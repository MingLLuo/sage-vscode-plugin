# Roadmap

## Phase 0: Repository Bootstrap

- Initialize repository structure and package boundaries.
- Add governance, process, and progress documentation.
- Establish minimal root scripts and CI placeholders.

## Phase 1: Editor MVP

- Register the `sagemath` language.
- Start the LSP client and `pygls` server successfully.
- Add baseline commands and environment display.

## Phase 2: Source Intelligence

- Add `.sage` parsing strategy and source mapping rules.
- Expand hover, completion, diagnostics, and definition behavior.
- Introduce fixture-based regression coverage.

## Phase 3: Interactive Workflows

- Improve run-current-file and run-selection flows.
- Prepare notebook and kernel integration boundaries.
- Add richer documentation and environment diagnostics.

## Phase 4: Release Quality

- Add packaging and smoke-test coverage.
- Improve observability, compatibility tracking, and release automation.
