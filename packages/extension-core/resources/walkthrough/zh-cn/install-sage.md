# 安装或选择 SageMath

编辑功能（语法高亮、悬停提示、跳转到定义、补全、查找引用）不需要安装 Sage。运行文件、REPL 和运行时文档需要 SageMath。

- **已安装 Sage：** 扩展会自动在 `PATH` 和常见安装位置查找 `sage`。状态栏会显示检测到的版本，例如 `Sage: 就绪（SageMath 10.8）`。
- **Sage 装在别处或没有被检测到：** [选择 Sage 解释器](command:sage.selectInterpreter)，选择检测到的安装，或输入 `sage` 可执行文件的路径。
- **还没有安装 Sage：** 参考 [SageMath 安装指南](https://doc.sagemath.org/html/en/installation/index.html)。Windows 上请在 WSL 中安装 Sage，并通过 WSL 扩展打开文件夹。

如果状态栏显示 `未找到 Sage`，说明配置的路径无法启动。
