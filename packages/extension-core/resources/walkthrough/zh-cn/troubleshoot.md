# 遇到问题时

点击状态栏上的 **Sage**。菜单最前面是最常用的修复方法：

- **重启语言服务器**：功能没有响应时使用。
- **选择 Sage 解释器**：运行时用错了 Sage，或者找不到 Sage 时使用。
- **查看日志**：查看扩展和语言服务器输出的信息。

[显示环境详情](command:sage.showEnvironmentDetails) 会列出解释器、源码根目录和索引状态。
[复制诊断信息包](command:sage.copySupportBundle) 会复制一份 JSON 报告，包含路径和设置，但不含源码内容、选中文本或环境变量，可直接附在问题报告里。
