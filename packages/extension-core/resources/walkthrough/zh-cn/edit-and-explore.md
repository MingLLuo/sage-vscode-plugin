# 浏览代码与使用 REPL

- 把鼠标**悬停**在 `PolynomialRing`、`matrix` 等名字上查看文档。
- **F12** 跳转到定义（包括 Sage 库源码）；**Shift+F12** 列出所有引用。
- **Shift+Enter** 把选中的代码发送到 Sage REPL；**Ctrl+Enter**（macOS 上是 **Cmd+Enter**）运行当前 `# %%` 单元格。
- [启动 REPL](command:sage.startRepl)：每个项目一个会话。
- [显示文档](command:sage.showDocumentation)：查看光标所在符号的完整文档。
