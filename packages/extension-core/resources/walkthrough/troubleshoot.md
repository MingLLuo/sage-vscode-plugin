# When something does not work

Click the **Sage** item in the status bar. The menu starts with the usual fixes:

- **Restart Language Server** when features stop responding.
- **Select Sage Interpreter** when runs use the wrong Sage or Sage is not found.
- **Show Logs** to see what the extension and the language server reported.

[Show Environment Details](command:sage.showEnvironmentDetails) lists the interpreter, source roots, and index state.
[Copy Support Bundle](command:sage.copySupportBundle) copies a JSON report with paths and settings, but no source
contents, selected text, or environment variables, ready to attach to an issue.
