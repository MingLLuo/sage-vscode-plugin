Check that the extension found the intended Sage source roots and that the Rust index is using a warm cache.

[Show Index Status](command:sage.showIndexStatus)

[Show Docs Status](command:sage.showDocsStatus)

[Copy Support Bundle](command:sage.copySupportBundle)

The status output should name the source roots, cache path, generation, pending jobs, and runtime docs state. The support
bundle copies a reviewable JSON report with paths and settings, but without source contents, selected text, or environment
variables.
