# Explore code and use the REPL

- **Hover** a name such as `PolynomialRing` or `matrix` to read its documentation.
- **F12** jumps to the definition, including Sage library sources; **Shift+F12** lists references.
- **Shift+Enter** sends the selected lines to the Sage REPL; **Ctrl+Enter** (**Cmd+Enter** on macOS) runs the
  current `# %%` cell.
- [Start REPL](command:sage.startRepl) opens one session per project.
- [Show Documentation](command:sage.showDocumentation) opens the full docstring for the symbol under the cursor.
